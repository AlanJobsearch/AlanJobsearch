London Job Search

A personal project aggregating live job offers for London from multiple public job-board APIs into one clean search interface.

About the project

This is a non-commercial, personal development project. Its goal is to build a simple job-search tool that collects vacancies advertised for the London area and lets the user filter them by keyword, profession, location and salary in one place.

All job data is fetched from public, officially provided APIs and links back to the original job boards. No data is resold or reused for commercial purposes.

Data sources (APIs used)

Adzuna API Jooble REST API Reed.co.uk Jobseeker API

Additional sources may be added during development.

Status

  • Stage: early development / MVP
  • Region: London, United Kingdom
  • Use of API data: display of job listings with direct links to the original advert
  • Expected traffic: low — personal use and small group of testers (< 1,000 visits/month)
